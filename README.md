# AI Engineering + Data Analytics Skills Hub

**Live app:** https://martino-ai-data-skills.streamlit.app/

An interactive radar of my skills across two tracks (AI engineering and
data analytics) where every score links to the evidence behind it.

## How scores work
Each factor is scored 0–4 on evidence, not confidence:
0 Unfamiliar · 1 Studied (notes) · 2 Prototyped (repo) · 3 Shipped (deployed or professional) · 4 Measured (shipped, with metrics)

Factors come from Chip Huyen's *AI Engineering* (O'Reilly, 2025) and the
Google Data Analytics Professional Certificate.
